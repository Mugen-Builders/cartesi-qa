# Templates

Starting points for the documents this repo produces. Copy, paste, fill in.

| Template | Use for |
|---|---|
| `cycle-plan-template.md` | Start-of-cycle plan, written by lead |
| `cycle-report-template.md` | End-of-cycle report, written by lead |
| `session-note-template.md` | Charter session output, written by tester |
| `bug-report-template.md` | Format for filing bugs upstream (not in this repo) |

Keep templates lean. If a template grows sections nobody fills in, trim it.
