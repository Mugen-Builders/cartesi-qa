# How a cycle folder is structured

This is an illustrative example, not a real cycle. Delete this folder once you have a real cycle to reference from.

## Contents that would be here

```
2026-04-v2.1-rc1/
├── plan.md                  # Filled in from templates/cycle-plan-template.md
├── report.md                # Filled in from templates/cycle-report-template.md
└── session-notes/
    ├── break-the-claimer-2026-04-15.md       # From templates/session-note-template.md
    ├── stress-evm-reader-2026-04-16.md
    └── misuse-the-cli-2026-04-17.md
```

## Workflow reminder

1. At cycle start: lead creates the cycle folder and writes `plan.md`.
2. During the cycle: testers add session notes as they complete charters.
3. At cycle end: lead writes `report.md`, linking to session notes.
4. The folder becomes permanent history. Do not delete old cycles.
